# Study Tracker

A small, offline-first Android study tracker with:

- Unlimited timer (HH:MM:SS)
- Start / pause / save / reset
- Optional subject field
- Built-in monthly calendar
- Daily minutes stored locally
- Current streak
- Simple stats and last-7-days view
- No ads, analytics SDKs, accounts, or internet permission

## Build
Open the project in a recent Android Studio and sync/build the project.

Tooling is pinned to Android Gradle Plugin 9.4.0, Gradle 9.6.0, Kotlin 2.4.10, and Compose BOM 2026.09.00.
